## Overview

### The challenge

Users should be able to:

- Complete the form and see a success toast message upon successful submission
- Receive form validation messages if:
  - A required field has been missed
  - The email address is not formatted correctly
- Complete the form only using their keyboard
- Have inputs, error messages, and the success message announced on their screen reader
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

### What I learned

This challenge helped me improve my understanding of form validation and responsive layouts.

I learned how to use JavaScript to validate form inputs and display appropriate feedback to the user. I also practiced controlling the visibility of elements after a form submission.

One of the main things I worked on was positioning the success message independently from the form. I used absolute positioning and responsive CSS so that the success message could appear without unnecessarily pushing the form down.

I also improved my understanding of responsive positioning by adjusting the success message for smaller screens so that it remains centered and visually balanced on mobile devices.
